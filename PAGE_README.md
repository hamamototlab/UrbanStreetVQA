# UrbanStreetVQA project page

GitHub Pages site for "UrbanStreetVQA: A Benchmark for Visual Understanding of Urban Street Views" (ACCV 2026).

## Files
- `index.html` — the page (single file, no build step)
- `static/images/` — figures

## Before publishing
1. Replace the three `coming soon` buttons with real links (Paper / Code / Dataset) and remove `class="soon"`.
2. Add acknowledgments in the footer if needed.

## Deploy
Settings → Pages → Source: "Deploy from a branch" → Branch: `gh-pages` / `(root)`.
The page will be served at `https://<user>.github.io/<repo>/`.
